Section 5 — Beyond the Résumé. A single scattered note: a quote, mantra or unfinished thought, angled as if pinned to a physical desk.

Consumer provides the note text (short — this is a fragment, not a paragraph) and, optionally, a rotation override; the reference set rotates between −2deg and +2deg and staggers vertically by a `space-8`–`space-24` step per card.

Do:
- `.ds-card` base, text in `body`/`text-primary`, set in italic — this is the one place on the page italic body copy is used, marking it as personal rather than descriptive.
- Rotate every note card individually within −2deg to +2deg; no two adjacent cards share the same angle.
- Keep each note to one short line or fragment — this is the system's only place for genuinely informal, unresolved voice (see Content fundamentals).

Don't:
- Don't rotate anything outside this component — the tilt is specifically what marks Section 5 as "the desk," and it would read as a bug anywhere else on the page.
- Don't add an author label or date; these read as private notes, not attributed quotes.
