# Portfolio Site

Personal portfolio website for Samuel Ehret, built with Next.js, TypeScript,
and Tailwind CSS (App Router). See `PROJECT_NOTES.md` for the project plan
and progress log.

## Getting Started

Install dependencies, then run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result. Start
editing the page by modifying `src/app/page.tsx` — it auto-updates as you
save.

## Structure

- `src/app/` — pages and layout (Next.js App Router)
- `public/` — static assets (images, icons)
- `PROJECT_NOTES.md` — plan, progress, and library notes for this project

## Deploy

The easiest way to deploy is [Vercel](https://vercel.com/new), which connects
directly to this GitHub repo and auto-deploys on push.
